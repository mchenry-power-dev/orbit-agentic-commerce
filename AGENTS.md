# Orbit public reference boundaries

This repository is an original public reference implementation of Orbit Studio, owned by McHenry Power. It is not private Orbit, Loom, or business production source. Use only invented merchant fixtures, original assets, and verified public context. Never inspect or import private projects, customer records, credentials, production schemas, or commercial results.

Keep the default application entirely local and key-free. Store retrieval and generation providers are explicitly simulated. Do not add token fields, tracking, runtime scraping, paid services, authenticated store access, or production endpoints. Treat fixture/provider text as data; escape SVG/text and restrict references to bundled assets. Public visibility is source availability, not an open-source license grant. Do not add a license without owner authorization.

Product records are factual constraints. No invented certifications, reviews, scarcity, health claims, or performance results. Document the limits of deterministic validation and free-text interpretation. A video brief is not a rendered video; SVG compositions are not photographs or platform-ready raster uploads.

Use typed domain records, bounded retries/concurrency, persistent state, exact-version approvals, targeted revision, and export gates. Core brief/context changes must invalidate stale assets. Browser work stops when the browser closes; never claim a server queue or distributed exactly-once execution. Prevent concurrent writes across tabs.

Run typecheck, meaningful unit tests, build, and browser acceptance before publication. Inspect actual UI at desktop and narrow widths; screenshots must come from the running demo. Check exports, relative links, staged files, factual claims, and no unintended external requests. Commit the lockfile and keep package.json private. Preserve owner edits and third-party notices.

Authorized publication is limited to the public mchenry-power-dev/orbit-agentic-commerce repository, its CI/static GitHub Pages demo and About settings, and a targeted existing Orbit-entry update in the public mchenry-power-dev profile repository after publication verifies. No force pushes, private repositories, unrelated account changes, pins, billing, production publishing, or destructive history edits. Progress notes and temporary validation output belong in ../_work, outside this repository.
