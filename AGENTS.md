# Orbit public reference boundaries

This repository is an original public reference implementation of Orbit Studio, owned by McHenry Power. It is not private Orbit, Loom, or business production source. V2 may use a small curated snapshot of owner-authorized public Cosmic Cat Coffee Co. materials, user-owned uploads, original compositions, and verified public context. Preserve the fictional V1 fixtures for saved campaigns and regression tests. Never inspect or import private projects, customer records, credentials, production schemas, or commercial results.

Keep an excellent local, key-free sample experience. Distinguish prebuilt samples, local photo composition, and configured live generation explicitly. Public HTTPS import and semantic/image generation may use a minimal protected service, with bounded input/output, safe URL/DNS/redirect checks, authentication/abuse controls, and server-only credentials. No paid calls or public paid inference without an explicit owner-approved runtime and cost ceiling. Do not add token fields, tracking, authenticated store access, or live publishing. Treat imported/provider text as untrusted data; never execute scripts or active markup. Public visibility is source availability, not an open-source license grant. Do not add a license without owner authorization.

The owner has authorized the no-key V2 release through the existing GitHub Pages workflow. Provider/runtime approval is not a prerequisite for this static release. Hosted capabilities are bundled context, owned uploads, supported local compositions, review and export. Public URL import is local-service-only; live semantic/image/video generation is deferred. Production builds must not contact local or remote service endpoints. Preserve the protected local service and adapter tests for future development, without provisioning services, requesting provider credentials or making paid calls for this release.

Product records are factual constraints. No invented certifications, reviews, scarcity, health claims, or performance results. Document the limits of deterministic validation and free-text interpretation. A video brief is not a rendered video; SVG compositions are not photographs or platform-ready raster uploads.

Use typed domain records, bounded retries/concurrency, persistent state, exact-version approvals, targeted revision, and export gates. Core brief/context changes must invalidate stale assets. Browser work stops when the browser closes; never claim a server queue or distributed exactly-once execution. Prevent concurrent writes across tabs.

Run typecheck, meaningful unit tests, build, and browser acceptance before publication. Inspect actual UI at desktop and narrow widths; screenshots must come from the running demo. Check exports, relative links, staged files, factual claims, and no unintended external requests. Commit the lockfile and keep package.json private. Preserve owner edits and third-party notices.

Authorized publication is limited to the public mchenry-power-dev/orbit-agentic-commerce repository and its existing CI/static GitHub Pages demo. Do not modify the profile README, Enterprise IQ, Loom or other repositories. No force pushes, branch-protection bypasses, private repositories, unrelated account changes, pins, billing, commercial platform publishing or destructive history edits. Progress notes and temporary validation output belong in ../_work, outside this repository.
