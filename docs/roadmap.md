# Direction and release boundaries

Orbit Studio is the first module of Orbit™ — Agentic Commerce OS. It coordinates catalog context, creative production, responsive pages, review and destination handoff. The current public reference uses existing GitHub Pages, original product photography and browser-local composition. It provisions no paid provider or backend.

| Available now                                                                   | Future work                                        | Evidence required                                                                                       |
| ------------------------------------------------------------------------------- | -------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Curated catalog snapshot, explicit anonymous public reads and local file import | Authenticated production store integration         | Scoped authorization, synchronization, tenant isolation and safe reconciliation                         |
| Two photographic composition systems and actual PNG/JPEG variants               | Live semantic/image generation                     | Approved runtime/cost ceiling, contrasting briefs, source fidelity, cancellation and failure acceptance |
| Browser-local drafts, exact approvals and recovery                              | Durable merchant jobs and synchronization          | Authentication, migration, backups and operational recovery                                             |
| Destination ZIPs and clearly simulated channel handoffs                         | Real storefront/ad-account publishing              | Scoped account access, preview/diff, exact-version write authorization and audit history                |
| Video briefs and explicit Video required findings                               | Finished video/audio production                    | Actual encoding, duration/bitrate/safe areas, rights and policy review                                  |
| Review → revise → review                                                        | Performance-informed creative/page/budget feedback | Consented observations, defined experiments and evidence against baselines                              |

Cosmic Cat Coffee Co. is the owner-authorized customer-zero brand; its dated demo catalog is not a production store connection. Aster and Harbor remain fictional regression data. Public catalog reads establish source retrieval, not store-admin authorization or continuous synchronization.

Local handoff completion means a record and package were prepared in this browser. It does not send assets, authenticate accounts, activate a campaign, update a storefront or change spend. TikTok's supported video placement remains blocked without finished video. Meta mappings retain explicit unknown requirements. [Channel scope](channel-handoff.md).

No measured time saving, quality score, conversion lift, revenue, ROI or live advertising performance is reported. Visual inspection and local tests establish the specific behaviors recorded in [validation](testing-and-evaluation.md), not field performance or physical-device acceptance.

Arbitrary public-page import remains **Local service required**; the static app makes no localhost calls. Live semantic/image/video adapters and protected service tests remain for later development. Paid-provider approval is not a condition of this no-key release. [Runtime boundary](provider-and-runtime.md).
