# Testing and evaluation

Tests establish specific implemented behaviors of a deterministic public reference. They do not establish creative quality, semantic understanding, advertising approval, conversion lift, ROI, security certification, or model performance.

## Reproduce the checks

```sh
npm ci
npm run typecheck
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm run check
```

Recorded toolchain: Node 24.18.0 and npm 11.16.0. Browser tooling is development-only; the installed sample app needs no paid services, model keys, or runtime external API.

## Behavioral coverage

| Area | Assertions that matter |
| --- | --- |
| Brief/context | Required fields; selected products; reference inclusion/exclusion and provenance |
| Validation | Supported product facts and prohibited phrases; weighted text lengths/counts; dimensions, blueprint completeness, active-SVG rejection |
| Orchestration | Timeout and bounded attempts; partial failure; refresh recovery; duplicate-start guard |
| Revision | Change one specification; preserve unrelated outputs; invalidate the edited/regenerated version's approval |
| Export | Missing/stale/invalid/unreviewed outputs block; traversal/device-name safety; formula-safe review CSV; ZIP/manifest approved-version matching |
| Persistence/reset | Saved brief/revisions/events/approvals restore; confirmed reset restores local sample state |
| Browser journey | Sample → create → review → revise → approve → ZIP; clipboard/brief downloads; failure/refresh recovery; stale edits; household single-product campaign; second-tab lock |
| Browser usability | Labels, modal focus/Escape/focus return, no narrow overflow, confirmed/reset persistence; no page/console errors or external demo requests |

## Limits

Selected keyboard/focus and responsive checks do not establish accessibility certification. Browser-local recovery is not a server queue guarantee; closing the browser stops work. Fixture failures do not characterize real vendor reliability. Channel checks cover a Performance Max-oriented subset; SVG drafts and the copy CSV do not establish upload/import readiness. See [channel specifications](channel-specs.md) and [trust boundaries](source-and-asset-notes.md).
